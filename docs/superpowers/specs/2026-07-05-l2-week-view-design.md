## 0. ズーム階層の再定義

Google Calendar に沿った 年→月→週→日 の4段階。

| レベル | 内容 | 状態 |
|--------|------|------|
| L0 | 年間 overview（12ヶ月俯瞰） | 実装済み |
| L1 | 月間 overview（単月） | 実装済み |
| **L2** | **週間 overview（Google週表示）** | **本設計** |
| L3 | 日間 overview（Google日表示） | 将来 |

## 1. 目的とスコープ

L1（月）から日をクリックして、その日を含む**週**を Google Calendar 風の時間グリッドで表示する。イベント（予定）は将来機能のため、MVP では**グリッドの骨組み**（時間×7日・今日/祝日/土休/現在時刻ライン）を表示する。

**対象**: L1 ↔ L2。
**対象外（YAGNI）**: イベント/予定の表示・作成、L3 日ビュー、ドラッグ操作、六曜。

## 2. 状態モデルとURL

ズーム状態に `week` レベルを追加（`day` は将来のため予約）。

```
type ZoomState =
  | { level: "overview"; year }
  | { level: "month"; year; month }
  | { level: "week"; year; month; day }   // day = 週内の基準日
  | { level: "day"; year; month; day }     // 将来
```

| URL | レベル |
|-----|--------|
| `/?y=2026` | overview |
| `/?y=2026&m=7` | month |
| `/?y=2026&m=7&d=5&v=week` | week（7/5 を含む週） |
| `/?y=2026&m=7&d=5&v=day` | day（将来） |

- `d` は基準日、`v` は week/day を区別する。`v` 無し＋`d`有りは overview/month 判定にフォールバック。
- `parseZoom` / `zoomToQuery` を拡張（TDD）。年は 1950–2150 にクランプ、月1–12、日1–31。

## 3. 入口・戻り（クリックで深入り）

- **入口**: L1 月ビューの**日セルをクリック** → その日を含む週の L2（当日を強調）。
  - L1 の `MonthCard`（spacious）の日セルに onClick を追加し、`navigate({level:"week", year, month, day}, "push")`。
- **戻り**: `‹ 戻る` ボタン ／ `ESC` ／ ブラウザ戻る → L1 月。
- **将来**: L2 週内の日ヘッダー/列クリック → L3 日（本増分では実装せず、フックのみ用意可）。

## 4. 週ビューのレイアウト（Google風骨組み）

```
┌─────────────────────────────────────────────┐
│ ‹戻る   2026年7月5日〜11日の週     ‹週 週›     │  ← ナビ（前週/次週）
├──────┬───────────────────────────────────────┤
│      │ 日5  月6  火7  水8  木9  金10 土11      │  ← 曜日+日付ヘッダー（今日強調・土休色・祝日）
│ 終日 │ [祝日/週末の帯]                          │  ← 終日行
├──────┼───────────────────────────────────────┤
│ 0時  │ ┆    ┆    ┆    ┆    ┆    ┆             │  ← 時間×7日グリッド
│ 1時  │ ┄┄┄┄┄┄┄┄┄┄┄┄┄┄ 今 ━━━━━┄┄┄┄ (今ライン)│     （0〜23時・内部スクロール）
│ …   │                                         │
│ 23時 │                                         │
└──────┴───────────────────────────────────────┘
```

- **時間軸（左列）**: 0〜23 時のラベル。
- **日ヘッダー（上）**: 各日の曜日＋日付。今日=強調、日祝=赤、土=水色（既存トークン）。
- **終日行**: 祝日名や週末の帯を表示（イベントは将来）。
- **本体グリッド**: 横線=毎時の区切り、縦線=日境界（既存の罫線思想を踏襲）。
- **今ライン**: 今日の列に現在時刻（client の時:分）の水平線。
- **時間範囲**: 0–23 時をすべて描画し、**本体は内部スクロール**。入場時に**現在時刻付近へ自動スクロール**。
- **週開始**: 設定（既定=日曜）を踏襲。

## 5. 週の算出と表示範囲

- 基準日を含む週 = 週開始曜日から7日間。
- 週が月をまたぐ場合も7日を表示（前月/翌月の日は日付のみ、当月外として淡色）。

## 6. ドメイン（TDD）

- `buildWeekView(refYear, refMonth, refDay, today, settings): WeekView`
  - `WeekView = { days: WeekDay[7]; ... }`
  - `WeekDay = { year; month; day; weekday; isToday; isHoliday; holidayName?; isSaturday; isSunday; inRefMonth }`
  - 週開始から7日を算出。祝日は `getHoliday`、土休は weekday から。純粋関数・テスト。
- `parseZoom`/`zoomToQuery`：week（`v=week`）の相互変換をテスト。
- 「今ライン」の位置＝現在時刻→縦位置（分→px）の純粋関数を切り出しテスト（例 `minutesToOffset`）。

## 7. コンポーネント構成

```
CalendarApp
 └─ level 分岐:
     overview → OverviewBody（L0）
     month    → MonthDetail（L1）※日セルに onClick 追加
     week     → WeekView（新・L2）
```

- `WeekView`（新）: ナビ（戻る/前週/次週）＋ヘッダー＋終日行＋時間グリッド＋今ライン。内部スクロール。
- `MonthDetail` の `MonthCard`（spacious）: 日セルクリックで週へ（onDayClick を伝播）。

## 8. 遷移・レスポンシブ

- View Transitions（日セル→週へモーフ）。非対応/reduced-motion は即時フォールバック。
- 広い画面: 7日を横並び（Google風）。
- **狭い画面（例 <768px）**: 週グリッドは**横スクロール**で7日を維持（各列に最小幅）。時間軸左列は sticky。<!-- 要レビュー: 極小画面での最小列幅は実装時に調整 -->
